# 가계부 CLI (ledger)

작성자: 엄혜인
작성일: 2026-07-28

## 1. 무엇을 만드나

터미널에서 지출을 한 줄로 기록하고, 나중에 찾아보거나 합계를 볼 수 있는 개인 가계부 프로그램.
화면(GUI) 없이 명령어로만 동작하는 CLI 프로그램이다.

## 2. 누가 쓰나

나 자신. 하루에 몇 번, 돈을 쓴 직후에 빠르게 한 줄 적는 용도.
"기록이 귀찮아서 안 하게 되는" 문제를 줄이는 게 목적이므로, **입력이 짧고 빨라야 한다**는 게 최우선 제약이다.

## 3. 왜 만드나

- 가계부 앱은 켜고 화면 넘기는 게 번거로워서 결국 안 쓰게 된다.
- 터미널은 이미 켜져 있으니, 명령 한 줄이면 기록이 끝난다.
- (학습 목적) 파일 읽기·쓰기, 명령행 인자 처리, 데이터 집계라는 기본기를 한 프로그램 안에서 다 다뤄본다.

## 4. 데이터 모델

지출 한 건은 다음 5개 항목을 가진다.

| 항목 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `id` | 정수 | 자동 | 항목을 지목할 때 쓰는 번호. 1부터 증가. |
| `date` | 문자열 `YYYY-MM-DD` | 아니오 | 생략하면 오늘 날짜가 자동으로 들어간다. |
| `amount` | 정수 | 예 | 원 단위. 소수점 없음. |
| `category` | 문자열 | 예 | 자유 입력 (예: 식비, 교통, 카페) |
| `memo` | 문자열 | 아니오 | 짧은 설명 |

### 저장 방식

- `data.json` 파일 하나에 전체 기록을 저장한다.
- 형태: `{"next_id": 4, "records": [ {...}, {...} ]}`
- JSON을 고른 이유: 메모장으로 열어서 내용을 눈으로 확인할 수 있어서, 뭐가 잘못됐을 때 원인을 찾기 쉽다.

## 5. 기능 (명령어)

| 명령 | 하는 일 | 예시 |
|---|---|---|
| `add` | 지출 추가 | `python ledger.py add 8500 식비 --memo "점심 김치찌개"` |
| `list` | 전체 목록 보기 | `python ledger.py list` |
| `delete` | 번호로 삭제 | `python ledger.py delete 3` |
| `edit` | 번호로 수정 | `python ledger.py edit 3 --amount 9000` |
| `search` | 검색·필터 | `python ledger.py search --category 식비` |
| `stats` | 통계 요약 | `python ledger.py stats --month 2026-07` |

### 각 기능 상세

**add** — 금액과 카테고리는 필수, 날짜(`--date`)와 메모(`--memo`)는 선택.
날짜를 생략하면 오늘 날짜가 들어간다. 저장 후 "3번으로 저장됨" 처럼 부여된 번호를 알려준다.

**list** — 표 형태로 출력한다. 기본은 최신순. 맨 아래에 총 합계를 함께 보여준다.

**delete** — 번호로 지운다. 지우기 전에 해당 항목을 보여주고 y/n 확인을 받는다.
(실수로 지우는 게 이 프로그램에서 가장 아픈 사고라서 확인 절차를 둔다.)

**edit** — 번호를 지정하고, 바꾸고 싶은 항목만 옵션으로 준다. 안 준 항목은 그대로 둔다.

**search** — `--category`, `--keyword`(메모 안 검색), `--from`/`--to`(날짜 범위)를 조합할 수 있다.
결과에도 합계를 함께 보여준다.

**stats** — 기본은 이번 달. `--month 2026-07` 로 월 지정 가능.
출력: 총 지출액, 카테고리별 합계와 비중(%), 기록 건수, 하루 평균.

## 6. 카테고리 자유 입력의 위험과 대응

카테고리를 자유롭게 치면 "식비"와 "밥값"이 서로 다른 카테고리로 집계되어 통계가 망가진다.
완전히 막지는 않되, 다음으로 완화한다.

- `add` 실행 시, 지금까지 쓴 카테고리 목록을 먼저 한 줄로 보여준다.
- 새 카테고리를 입력하면 "'밥값'은 처음 쓰는 카테고리입니다" 라고 알려준다. (막지는 않음)
- `categories` 명령으로 현재 쓰고 있는 카테고리 목록을 언제든 확인할 수 있게 한다.

## 7. 오늘 만들지 않는 것 (범위 밖)

의도적으로 뺀다. 하루 안에 끝내는 게 우선이기 때문.

- 수입 기록과 잔액 계산 (지출만 다룬다)
- 예산 설정·초과 알림
- 그래프·차트
- 여러 사용자, 로그인
- 데이터베이스 (JSON 파일로 충분하다)

## 8. 완료 기준

아래가 전부 되면 오늘 끝난 것으로 본다.

1. 지출 3건을 넣고 `list`로 확인할 수 있다.
2. 프로그램을 껐다 켜도 기록이 남아 있다.
3. 1건을 지우고 1건을 수정할 수 있다.
4. `search --category 식비` 가 해당 항목만 보여준다.
5. `stats` 가 카테고리별 합계를 보여준다.
6. 잘못된 입력(금액에 글자를 넣는 등)에도 프로그램이 죽지 않고 안내 메시지를 낸다.

## 9. 구현 순서

한 단계씩 만들고, 매번 직접 실행해서 확인한 뒤 커밋한다.

1. **뼈대** — `ledger.py` 파일 생성, 명령어를 받아들이는 구조(argparse) 만들기. `add`가 화면에 출력만 하고 저장은 아직 안 함.
2. **저장/불러오기** — `data.json` 읽고 쓰는 함수. `add` 가 실제로 저장되고 `list` 로 보이게 함. ← 여기서 완료 기준 1, 2 달성
3. **delete / edit** — 번호로 지목해서 지우고 고치기. 삭제 확인 절차 포함.
4. **search** — 카테고리·키워드·날짜 범위 필터.
5. **stats** — 월별 집계와 카테고리별 비중.
6. **다듬기** — 잘못된 입력 처리, 출력 정렬, `categories` 명령, README 작성.

시간이 부족하면 4~5번을 잘라낸다. 1~3번까지만 돼도 "동작하는 물건"이다.

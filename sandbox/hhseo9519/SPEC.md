# 관심 종목 일일 스냅샷 도구 (Watchlist Snapshot)

## 무엇을

`watchlist.txt`에 적어둔 해외 종목 티커들을 한 번에 조회해서, 각 종목의 **현재가 / 전일 종가 / 등락률 / 거래량**을
터미널에 표로 보여주고 CSV 파일로도 저장하는 CLI 도구.

## 누구를 위해

나(hhseo9519) 자신. 관심 종목 여러 개를 매번 증권 앱에서 하나씩 확인하는 게 번거로워서,
터미널에서 한 번에 조회하고 기록도 남기고 싶음.

## 왜

- 여러 종목을 앱에서 매번 검색해서 보는 게 반복 작업이라 귀찮음
- 조회한 시점의 데이터를 CSV로 남겨두면 나중에 "그때 그 종목이 얼마였지" 확인 가능

## 범위

### 데이터 소스
- `yfinance` 라이브러리 사용 (무료, API 키 불필요)
- 해외 종목만 지원 (미국 등, 예: AAPL, TSLA, MSFT)

### 입력
- 프로젝트 폴더 안 `watchlist.txt` 파일
- 한 줄에 티커 하나씩 작성 (예: `AAPL`, `TSLA`, `MSFT`)

### 출력
- 터미널: 티커 / 현재가 / 전일 종가 / 등락률(%) / 거래량을 표 형태로 출력
- CSV 파일: `data/snapshot_YYYY-MM-DD.csv` 형식으로 저장 (조회 날짜가 파일명에 포함)

### 기능 (Must have)
1. `watchlist.txt`를 읽어서 티커 목록을 가져온다
2. 각 티커에 대해 yfinance로 현재가/전일 종가/거래량을 조회하고 등락률을 계산한다
3. 조회 결과를 터미널에 표로 출력한다
4. 조회 결과를 CSV로 저장한다 (파일명에 날짜 포함)
5. 존재하지 않는 티커나 네트워크 오류가 나면 해당 종목만 건너뛰고 에러 메시지를 출력한 뒤 나머지는 계속 진행한다

### 제외 (Not now — 나중에 하고 싶으면 그때 다시 스펙 잡기)
- 실시간 자동 새로고침이나 스케줄링(매일 자동 실행)
- 이메일/슬랙 등 알림 기능
- 차트/그래프 시각화
- 국내 종목(코스피/코스닥) 지원
- 포트폴리오 매입가 기반 수익률 계산

## 구현 순서

1. `yfinance` 설치 + `watchlist.txt` 읽는 기능
2. 티커별 데이터 조회 + 터미널 표 출력
3. CSV 저장 기능 추가
4. 잘못된 티커 / 네트워크 오류 처리 보완
5. `README.md` 작성 (설치 방법, 실행 방법, watchlist.txt 예시)

## 실행 방식 (예상)

```bash
python snapshot.py
```

`watchlist.txt`에 있는 종목을 전부 조회 (실행 시 인자로 티커를 따로 받지는 않음 — 종목 관리는 파일로만 함).

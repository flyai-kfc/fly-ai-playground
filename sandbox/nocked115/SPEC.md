# 가계부 기록기 SPEC

## 무엇을 만드나요
터미널(CLI)에서 수입/지출을 기록하고, 지금까지 기록을 조회하고,
월별·카테고리별로 얼마 썼는지 합계를 볼 수 있는 개인용 가계부 프로그램.

## 누구를 위해
- 나 혼자 쓰는 용도. 로그인이나 여러 사용자 구분 없음.

## 왜 만드나요
- Git·에이전트 협업 연습(fly-ai-playground)의 실습 프로젝트.
- 결과물보다 "요구사항을 스펙으로 정리하고 단계별로 구현하는 흐름"을 익히는 게 목적.

## 기술 스택
- **언어**: Python (표준 라이브러리만 사용, 외부 패키지 설치 없이 바로 실행)
- **저장 형식**: CSV 파일 (엑셀/구글시트로 바로 열어볼 수 있음)
- **저장 위치**: `sandbox/nocked115/data/ledger.csv` (프로그램을 껐다 켜도 기록이 남음)

## 핵심 기능 (이번에 만드는 것)

### 1. 기록 추가
- 입력 항목: 날짜, 종류(수입/지출), 카테고리, 금액, 메모
- 날짜를 안 적으면 오늘 날짜로 자동 저장
- 카테고리는 자유 입력 텍스트(예: 식비, 교통, 월급 등) — 목록을 딱 정해두지 않음

### 2. 전체 내역 조회
- 지금까지 기록한 것을 표 형태로 최신순(또는 날짜순)으로 출력

### 3. 월별 / 카테고리별 합계
- "이번 달 총 지출", "이번 달 총 수입" 같은 월별 합계
- 카테고리별로 얼마씩 썼는지 합계

## 이번에는 만들지 않는 것 (제외 기능)
- 예산 설정 및 초과 알림 — 나중에 필요하면 추가 가능한 영역으로 남겨둠
- 여러 사용자 구분/로그인 — 혼자 쓰는 용도라 불필요
- 웹 UI, 데이터베이스(SQLite 등) — 지금은 CLI + CSV로 충분

## CLI 명령어 설계 (초안)
```
python ledger.py add       # 기록 추가 (대화형으로 하나씩 물어봄)
python ledger.py list      # 전체 내역 조회
python ledger.py summary   # 월별 · 카테고리별 합계
```

## 데이터 구조 (CSV 컬럼)
| 컬럼 | 설명 | 예시 |
|---|---|---|
| date | 날짜 (YYYY-MM-DD) | 2026-07-28 |
| type | income(수입) 또는 expense(지출) | expense |
| category | 카테고리 | 식비 |
| amount | 금액(원, 정수) | 12000 |
| memo | 메모(선택) | 점심 |

## 미리 정해둔 것들 (구현 전 결정 사항)
- CSV는 한글이 엑셀에서 깨지지 않도록 `utf-8-sig` 인코딩으로 저장합니다.
- 데이터 파일이 없으면 `add` 실행 시 자동으로 새로 만듭니다.
- 금액은 정수(원 단위)로만 다룹니다. 소수점/외화는 다루지 않습니다.

## 구현 순서 (제안)
1. `sandbox/nocked115/` 폴더 구조 잡기 (`README.md`, `data/` 폴더, 메인 스크립트 파일)
2. CSV 읽기/쓰기 기본 함수 작성 (파일 없으면 헤더와 함께 새로 생성)
3. `add` 명령 구현 → 입력 받아서 한 줄 추가, 직접 실행해서 CSV에 잘 쌓이는지 확인
4. `list` 명령 구현 → CSV를 표로 출력, 직접 눈으로 확인
5. `summary` 명령 구현 → 월별/카테고리별 합계 계산, 계산이 맞는지 손으로 검산
6. `README.md`에 실행 방법 작성
7. 브랜치 파서 커밋 → `sandbox/nocked115-가계부` 같은 브랜치명으로 PR 올리기

이 순서대로 하나씩 만들면서, 각 단계마다 직접 실행해 눈으로 확인하고 넘어가는 걸 추천합니다.
